# Jellyfin Tailscale
A Jellyfin authentication provider that uses Tailscale to authenticate users. 

## Installation
See [jellyfin-tailscale](https://robotholocaust.com/jellyfin-tailscale) for instructions. This repo is for reporting issues. Full source code is available from that website as well.

## Why no code here?
This project is open-source but not open-collaboration. Free free to do whatever you want with it so long as you follow the license.
